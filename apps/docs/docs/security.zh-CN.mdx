# 安全模型

`@amamo/mdx` 只保护特定构建产物，不会把不可信 MDX 变安全。请把作者、配置模块、生成文件和
部署目标当作彼此独立的信任边界。

## MDX 可以执行代码

MDX 可以包含 ESM import 和 JavaScript 表达式。编译器会把它们输出到 JavaScript 模块中，
宿主可能在打包、import、服务端渲染或客户端渲染时执行这些代码。

只编译你信任、并允许其以宿主应用权限运行代码的作者内容。JSON Schema 只校验 frontmatter
数据，不会检查或沙箱化 MDX 程序。

## 敏感 frontmatter

声明不得进入成功编译产物的顶层字段：

```ts
collections: {
  posts: {
    directory: 'content/posts',
    schema: { /* ... */ },
    sensitive: ['accessToken', 'internalNotes'],
  },
}
```

成功编译的顺序是：

1. 解析全部 YAML frontmatter。
2. 对完整对象应用 schema 默认值并校验。
3. 把每个顶层敏感字段移出公开 frontmatter。
4. 只计算配置明确允许的 manifest 投影。
5. 输出不含敏感字段明文的模块、记录和 manifest。

`sensitive` 只匹配顶层名称。声明 `credentials` 会移除整个顶层 `credentials` 值，而不是单独
分类其中的 `credentials.password`。

## 诊断可能包含提交值

Schema 校验发生在敏感字段移除之前，validator 消息可能引用非法值。即使字段列在
`sensitive` 中，也不要把原始编译错误或构建日志返回给不可信作者。

成功结果的 warning 诊断保存在文档记录中。编译器和 Vite 插件不会自动打印它们，因此由调用方
控制暴露位置。

## Manifest 投影

敏感源只能使用以下 transform：

```ts
fields: {
  tokenPresent: { from: 'accessToken', transform: 'exists' },
  tokenFingerprint: { from: 'accessToken', transform: 'sha256' },
}
```

- `exists` 只暴露值是否存在且非 null。
- `sha256` 输出确定性的无盐 digest。

原始 SHA-256 不是密码哈希函数。不要用这个投影存储或校验人类密码；请在宿主中使用专门的
密码 KDF 和身份验证系统。只有在值本身有足够高熵，并且可以接受泄露相等关系时，确定性摘要
才可能适用。

`public`、`server` 之类的 manifest 名称没有访问控制语义。编译器只负责写配置路径；该路径
是否公开由部署系统决定。

## Markdown 媒体路径包含

全新编译时，由 Markdown 产生的相对媒体会先从源文件归一化、检查是否位于 `root` 内；文件
存在时还会 canonicalize，并拒绝解析到 canonical root 之外的 symlink。外部 URL、绝对 URL、
fragment、协议相对 URL 和 data URL 不会经过本地文件检查。手写 MDX JSX 不会被重写。

Warm cache 命中只检查早先记录的依赖路径是否仍存在。如果 MDX 源码和配置未变化，但媒体
symlink 更换了目标，它不会再次 canonicalize。修改目标后，请删除受影响缓存，或在目标可能
变化期间保持缓存关闭。单次关闭缓存会重新检查路径，但不会替换旧缓存记录。

Manifest 的 `mediaUrl` transform 不同：它只按词法把相对值映射为 root-relative URL，既不
检查文件存在，也不创建 import。

## 配置只在 import 后被限制为数据

归一化会拒绝函数、访问器、symbol、类实例、循环引用、非有限数字和其它非 JSON-like 值。这
让归一化值足以参与指纹计算，但不会沙箱化创建该值的 JavaScript 或 TypeScript 配置模块。

指纹使用归一化数据的序列化结果，因此对象键顺序会影响指纹；即使两个对象语义相同，也可能
产生 cache miss。

## 缓存与产物写入

缓存记录包含公开 frontmatter、派生数据、安全投影、依赖、诊断和编译模块，不包含敏感字段
明文。高亮结果属于同一记录，不存在单独的磁盘高亮缓存。

缓存、manifest 和三个共享生成文件可以位于不同的配置目录。应根据各自内容保护这些路径，
不要假设它们全部位于 `generatedDirectory` 下。

共享生成文件和 manifest 会在写入前比较现有字节。它们与缓存记录都会通过同目录临时文件和
rename 完成整文件替换；缓存记录不会执行 TypeScript 侧的字节比较。读取方应当只会看到完整
旧文件或完整新文件，而不是写到一半的记录。

## 部署检查清单

- 只有可信作者能修改 MDX 及其 import。
- 顶层敏感字段已在配置中列出。
- 不向不可信用户暴露原始校验错误。
- 含私密元数据的 manifest 没有部署到公开路径。
- symlink 目标变化会强制执行全新媒体编译。
- 身份认证和密码存储不依赖 manifest 的 SHA-256 投影。
